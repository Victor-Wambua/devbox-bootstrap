Profiles

8 bundled profiles. Pick one or several: devbox plan --profile php-laravel,python. Your own profiles in ~/.devbox/profiles/ appear in devbox profiles too; here is how to write one.

Bundled devbox profiles: what each is, what it includes, and how many steps it resolves to
ProfileWhat it isIncludesSteps
base profile Core command-line tools: git, gh, jq, ripgrep, fd, fzf, bat, shellcheck, tmux none 10
data profile SQLite and DuckDB for quick data work base 12
editor profile Visual Studio Code with a curated extension list none 8
macos-defaults profile Curated, reversible macOS preferences (Finder, Dock, keyboard, text) none 11
node profile Node.js via fnm, tracking the current LTS base 13
php-laravel profile PHP, Composer, MySQL and Laravel Valet base 22
python profile Python managed by uv, with pinned interpreters base 13
salesforce profile Salesforce CLI (sf) on a managed Node LTS, with helper aliases node 16
